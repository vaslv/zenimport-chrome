# ZenImportChrome

Общение по-русски. План: docs/refactor/03-extension.md; журнал: docs/refactor/05-progress.md.
Самостоятельный Chrome MV3; SDK и backend — соседние независимые проекты.
Нет редакторов операций, сверок, options/SPA, инъекции продуктового UI и keepalive в банке.
Только popup, сбор истории по явной команде, настройки счетов и серверный контракт v1.
Не передавать токены backend странице банка; не хранить банковские auth-поля.
Тесты только с искусственными банком, ZenMoney и БД в изолированном Docker.
Живые банковские возможности подтверждать отдельно, не объявлять их по фикстурам.
Этапы последовательно, проверки и локальные коммиты. Без push, тегов, публикации.
