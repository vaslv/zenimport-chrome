# L9.4 — durable single-use outbox review

Scope: native immutable attempts, exact payload/target evidence, single-use dispatch
lease and conservative recovery. No HTTP financial gateway or product local mode.

Independent API and adversarial reviewers completed their final passes without
remaining findings. The adversarial pass inspected fixtures in summary mode;
the primary agent executed the tests. External cross-model CLI review remains
unavailable in this sandbox; these passes do not claim cross-model coverage.

Findings fixed before the gate:

- An authorization arriving between eligibility selection and matching could have
  inherited a newer snapshot without matching the new row. Reconciliation now
  checks the caller's initial stamp before writes and returns its final stamp.
- Resolved ownership/settings errors were left active. Adoption resolves scoped
  errors; intent preparation clears its scoped errors atomically with attempts.
- An expired unsettled outbox could enter migration hold before recovery, making
  its attempting rows unexportable. Source hold now requires a settled manifest;
  recovery retains the original UUID/payload and never authorizes another create.

Dispatch tolerates unrelated capture/status revisions but rechecks each immutable
intent, authorization, current settings, ownership exclusions and mirror/Root
fences. An active lease blocks independent mirror publication. Credential rotation,
expiry, migration or changed account settings deny dispatch. Scope-error cleanup
inside the intent transaction is bounded to 200 rows; larger pathological inputs
fail before preparing any new financial attempt.
