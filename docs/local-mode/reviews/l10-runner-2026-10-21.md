# L10.5 durable normal transfer runner and participant adapters

Each wake performs one bounded phase or chunk step. The coordinator saves the
request before dispatch and resolves lost mutation replies from authenticated
participant status with the same saved UUID/body/epoch. Queued/running server
work is polled instead of reenqueued. Temporary writer-lock contention is a
waiting state, preserving the same request. No financial SDK writer is called.

Native and server adapters implement the same participant interface. The source
must hand off before remote Root selection; native destination activation switches
Root atomically. The destination always remains awaiting explicit Sync. Finalized
chunk count, archive identity and permanent receipts are checked by the journal
and participant owners, not inferred from popup acknowledgment.

Independent API and adversarial reviews are clean after fixing the initially
unbounded source capture check: the existing partial `one_active_capture` index
provides a bounded atomic first-match check inside source_start's final Root CAS.
An unfinished capture is rejected before hold so it remains possible to stop it.
The earlier authority regression now expects this earlier rejection; its separate
in-flight-delivery snapshot rejection is retained.

Docker tests include actual worker death after irreversible handoff, dropped
start/handoff/activation responses, native graph equality and Chrome to the actual
Python HTTP API including chunk upload, asynchronous graph validation/activation
and no financial SDK requests. Python fixtures explicitly start only the portable
migration worker; the financial delivery worker remains disabled. Minimum-browser
and final regression evidence is recorded in progress.md.

This is the normal live-transfer engine. Production credential/setup ports,
cancellation/forward recovery UI, used-server joins and archive-only recovery
remain subsequent L10 tasks. It does not enable product local routing. External
cross-model CLI remains unavailable; no cross-model pass is claimed.
