# L10.10 native backup review

Independent API and adversarial source reviews completed. Fixtures/tests were
reviewed in summary mode. External cross-model CLI unavailable.

Backups have a separate owner and private chunk store (native schema v7); they
never fabricate participant operations, handoff receipts or activation rights.
An active snapshot requires exact Root, settled outbox and no active capture.
Its own Root/dataset hold stops all writers. Snapshot rebuilds use a fresh nonce;
every read/chunk/final transaction checks that nonce and hold. Retired-generation
snapshots require immutability and do not change the active remote Root.

Graph validation, complete chunk hash verification, readiness and hold release
precede download. Only verified-download acknowledgement permits bounded chunk
cleanup. Financial rows are retained. Interrupted/quota-limited exports keep their
own hold, can resume after full browser restart or can be cancelled safely. A late
cancelled builder cannot publish over a new writer.

Review fixes: exclude unfinished switch/join intents before a snapshot changes
Root epochs; reserve BOTH hold/release epochs before making the source unwritable.
The latter has native MAX_INT64 boundary tests proving no hold on rejection and
successful cancellation at the last valid starting epoch. Final reviewers report
no remaining findings. Docker evidence is recorded in progress.md.

Backup files are facts snapshots, not current-data transfer authorization. Manual
restore and replacement consent remain separate unfinished L10 tasks. Product
local routing is still disabled. Synthetic isolated services/data only.
