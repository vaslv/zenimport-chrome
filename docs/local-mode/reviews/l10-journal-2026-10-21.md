# L10.4 durable coordinator journal foundation

This checkpoint records intent, immutable command requests, integrity-checked
participant receipts, ordered chunk acknowledgments and bounded exclusive leases.
It does not run network effects, switch Root, activate a participant or implement
the full L10 UI. Authenticated participant adapters must verify status before
passing a receipt to this storage-private repository; a hash is not authentication.

Each command is saved before a future runner dispatches it. Lease expiry allows
recovery with the same saved request UUID/epoch/body. Late owners cannot record
progress. Only a completed journal permits a new switch; prior native records and
participant decisions remain retained. Creating a journal does not select a writer.
Credential UUID references are recorded; tokens and arbitrary response errors are
rejected. Phase progress requires cumulative receipt proofs, matching archive
identity, complete chunk ACKs before destination verification and the actual Root
mode/generation/reference before pointer commitment can be recorded.

API review found an initially accepted remote-to-local plan could preassign a
destination ID without its generation and become impossible to reserve. Creation
now requires no destination, and reservation records the pair together; strict
rehydration also rejects half-bound pairs. The matching regression is in
migration-journal.test.mjs. Adversarial review additionally found a stale Root coordinator and a reservation
pair that could poison future recovery. claim and both sides of each journal
mutation now verify the exact initial context or the matching native switch
transition, including credentials and paired destination IDs. Native regressions
prove rotation fences the old lease, own hold lost replies remain recoverable,
and a wrong reservation pair rolls back before a correct retry. Both final
independent reviews are clean. Docker evidence is in progress.md.

External cross-model CLI remains unavailable; no cross-model review is claimed.
