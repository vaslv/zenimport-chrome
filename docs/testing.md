## Готовая банковская страница при незавершённой загрузке ресурсов — 0.1.8

Коннектор определяет готовность по проверенному DOM выбранного счёта и
идентичности документа, а не по chrome.tabs.status=complete. Проверка и
запуск используют scripting.executeScript injectImmediately=true, чтобы
document_idle не задерживал их на готовой странице. Обработчик сам ждёт
нужные элементы; проверки счёта/документа/периода сохранены. Разрешения
расширения и финансовые запросы не изменены.

Основание Chrome API: https://developer.chrome.com/docs/extensions/reference/api/scripting
(проверено через Context7 16 октября 2026). По умолчанию executeScript ждёт
document_idle, injectImmediately разрешает выполнение до окончания загрузки.
Регрессии adapter.test.mjs: loading/complete, ещё не готовый DOM, переход на
вход, первая регистрация наблюдателя, отсутствие лишней перезагрузки,
сохранение documentIds при запуске. Фактическая банковская приёмка фиксируется
отдельно; модельные тесты не доказывают причину каждого живого сбоя.
