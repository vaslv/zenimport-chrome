# Подготовка ZenImport Chrome к GitHub

Репозиторий: https://github.com/vaslv/zenimport-chrome. Лицензия MIT.
Подготовлена распакованная сборка и ZIP 0.1.9; Chrome Web Store не публикуется.
Локальный origin связан с созданным репозиторием; его исходная лицензия сохранена.

```sh
./scripts/test-docker.sh
python3 scripts/build.py
```

`dist/extension/` загружается через chrome://extensions в режиме разработчика.
ZIP `dist/zenimport-chrome-0.1.9.zip` содержит только исходники расширения,
LICENSE и PRIVACY.md; серверные настройки, .env, тестовые данные, журналы,
SQLite и локальные профили браузера в него не попадают. Сборка воспроизводима:
фиксированный порядок/время ZIP-файлов, SHA256 выводится при сборке.

`.github/workflows/ci.yml` использует Docker с искусственными сервисами, без
настоящего банка/ZenMoney, и сохраняет ZIP. Отправки в Store, создания тегов или
GitHub Release в CI нет. Совместная приёмка с backend остаётся отдельной:
`./scripts/test-integration.sh ../ZenImportBackend`; она требует оба checkout,
но готовая сборка расширения — только этот репозиторий.

После отдельного разрешения: проверить чистоту Git и историю на секреты,
отправить подготовленные коммиты без force, дождаться CI. Для GitHub Release
потребуются отдельные разрешения на тег/push и публикацию; прикладывать только
проверенный ZIP и его SHA256. Само наличие этого документа ничего не публикует.

Первым публикуется `vaslv/zenmoney-python` (пакет zenmoney-python), затем backend
с закреплённой зависимостью SDK; расширение подключается к его HTTPS-адресу и
API_TOKEN. Токен ZenMoney в расширение не вводится.
Подробности данных: [PRIVACY.md](../PRIVACY.md).
